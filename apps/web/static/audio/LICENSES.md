# Bundled music

Every file here is a recording that its rights holder released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/): all rights waived, no
attribution required. The compositions themselves are long out of copyright. The files are the
MP3s published at the source, byte for byte; the SHA-1 below is the one the source lists.

Licences were checked against each collection's own metadata on 2026-10-13. Before adding a
track, check the licence at its source and add a row. A "Public Domain Mark" is not enough: it
is a statement about a work, not a waiver by whoever made the recording.
